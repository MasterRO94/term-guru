# Changelog

All notable changes to TermGuru are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning](https://semver.org/). Every version has a matching `vX.Y.Z` tag and GitHub release.

## [Unreleased]

## [0.2.2] - 2026-11-10

### Fixed

- No autocomplete and no `tgr` command when `~/.local/bin` is not on `PATH`, as on a stock Mac: the shell line now adds it. Run `Scripts/install.sh` or `tgr install` to update the line in `~/.zshrc` and `~/.bashrc`.

## [0.2.1] - 2026-11-10

### Added

- Your own completion specs: drop `<command>.js` into `~/.config/term-guru/specs` and run `tgr rescan`. They override the bundled ones.
- `Resources/custom-specs` for hand-written specs that ship with TermGuru.
- Completions for `tgr` itself, generated from the CLI at build time, including shell names for `tgr init` and alias names for `tgr alias rm`.
- `tgr specs --source` shows which directory each spec loads from; `tgr alias list --names` prints only names.

## [0.2.0] - 2026-11-10

### Added

- Updates from release tags: the app checks for a newer `vX.Y.Z` tag, offers **Update to X.Y.Z…** in the menu bar, then fetches the source, rebuilds, reinstalls and restarts. `tgr update` does the same from a terminal.
- **Settings › General › Updates** with a switch for the automatic check and a *Check Now* button.
- `tgr doctor` reports when a newer release is available.

### Changed

- `make update` runs `tgr update` instead of `git pull`.

## [0.1.2] - 2026-11-10

### Added

- App icon, generated by `make icon` from `Scripts/make-icon.swift`.

### Changed

- Menu bar icon matches the app icon instead of the `</>` symbol.

## [0.1.1] - 2026-11-10

### Fixed

- Build failed on machines with only the Command Line Tools (no Xcode) on the macOS 27 SDK.

### Added

- `Makefile` with shortcuts for building, installing, restarting, testing and releasing.

### Changed

- Return inserts the highlighted suggestion without pressing ↑/↓ first. It still runs the line as typed when the current word is empty or already complete.

## [0.1.0] - 2026-11-10

### Added

- Autocomplete popup at the terminal caret with a Liquid Glass list and description panel.
- zsh and bash 4+ integration: Tab inserts, ↑/↓ select, Esc hides.
- Suggestions from Fig completion specs (subcommands, options, arguments, generators) mixed with aliases, shell history, PATH commands and files.
- JetBrains caret plugin for PhpStorm, IntelliJ IDEA and other JetBrains IDEs; Accessibility-based caret lookup for other terminals.
- Setting for Return on a selected suggestion: insert it or run it. ⌘Return always runs it.
- `tgr` CLI: `doctor`, `rescan`, `alias`, `install`, `uninstall`, `settings`, `status`, `start`, `stop`, `restart`, `logs`, `specs`, `complete`.
- Settings window (General, Aliases, Diagnostics) and menu bar item.
